# ભાષા સપોર્ટ (i18n)

TolaMandi હાલમાં બે ભાષા સપોર્ટ કરે છે: **English (`en`)** અને **Gujarati (`gu`)**.

## Language switch

Language toggle વડે આખું UI તરત બદલાય છે:
- Header
- Settings
- Mobile operator UI

## કવરેજ

Navigation, dashboard, forms, validations, table labels અને messages બે ભાષામાં ઉપલબ્ધ છે.

<Callout title="Preference persistence" type="info">
  પસંદ કરેલી ભાષા navigation દરમિયાન જળવાય છે અને locale route દ્વારા નિયંત્રિત થાય છે.
</Callout>
