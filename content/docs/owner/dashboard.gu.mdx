# ઓનર ડેશબોર્ડ

**રૂટ:** `/dashboard`

આ પેજ આજના trading activityનું live overview આપે છે.

![Owner Dashboard](/screenshots/app-owner-dashboard.png)

## સ્ટેટ કાર્ડ્સ

| કાર્ડ | વર્ણન |
| --- | --- |
| **Total Bags** | આજના કુલ બેગ |
| **Total Weight** | કુલ નેટ વજન (kg) |
| **Total Amount** | કુલ રકમ (₹) |
| **Total Transactions** | આજના ટ્રાન્ઝેક્શનની સંખ્યા |

## ફિલ્ટર્સ

- Produce filter
- Grade filter
- Clear Filters

ફિલ્ટર લાગુ પડે ત્યારે બધાં cards અને tables અપડેટ થાય છે.

<Callout title="રિયલ-ટાઇમ" type="info">
  ઓપરેટર્સ નવા ટ્રાન્ઝેક્શન ઉમેરે ત્યારે ડેશબોર્ડ આંકડા તરત અપડેટ થાય છે.
</Callout>
