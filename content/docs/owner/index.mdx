# Organization Owner Guide

<Video src="https://czjrrypzshezcosigaxe.supabase.co/storage/v1/object/public/demo/Owner/Owner.mp4" title="Owner Overview" />

As an **Organization Owner**, you have full control over your market yard operations. You can manage multiple organizations, commission agents, operators, transactions, and billing — all from a unified dashboard.

<Callout title="Login" type="info">
  Owners log in at `/login` with email and password. After authentication, you are redirected to `/dashboard`.
</Callout>

## Quick Reference

| Feature | Access Level |
| --- | --- |
| Dashboard | All roles |
| Transactions | All roles |
| Masters (Commission Agents) | All roles |
| Operators | Owner and Buyer Admin only |
| Organization Settings | Owner only |
| Billing | Owner only |
| Settings | All roles |
| Org Switcher | Owner only (in header) |

## Multi-Organization Support

Owners can manage **multiple organizations** (market yards) from a single account:
- Use the **Org Switcher** dropdown in the header to switch context
- All data (transactions, agents, operators) filters based on the selected organization
- Create new organizations via the Org Switcher (subject to subscription limits)
- Suspended organizations are visually marked and cannot be accessed
