# નોટિફિકેશન્સ

Notification centerમાં transaction અને system સંબંધિત અપડેટ્સ મળે છે.

## સામાન્ય પ્રકારો

- Organization alerts
- Subscription/limit warnings
- Operator activity updates
- System announcements

<Callout title="ટિપ" type="info">
  અનપઢ notifications સમયસર વાંચો જેથી ઓપરેશનલ અવરોધ ટાળી શકાય.
</Callout>
