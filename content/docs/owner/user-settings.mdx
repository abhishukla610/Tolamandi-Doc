# User Settings

**Route:** `/settings`

Manage your personal account settings and notification preferences.

## Profile Section

| Field | Editable | Description |
| --- | --- | --- |
| **Full Name** | Yes | Your display name |
| **Email** | No | Login email (read-only, shown as disabled) |
| **Phone** | Yes | Contact phone number |
| **Role** | No | Shown as a badge (Owner / Admin) |
| **Language** | Yes | Toggle between English and Gujarati |

The language toggle switches the entire application interface instantly. Your preference is saved and applied on your next login.

## Notification Preferences

Toggle individual notification types on or off:

| Type | Description |
| --- | --- |
| Transaction notifications | When new weighments are recorded |
| System notifications | Platform announcements and alerts |
| Billing notifications | Subscription and billing updates |

Preferences are saved per-user and filter which notifications appear in the notification bell.
