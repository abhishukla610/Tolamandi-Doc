# ઓર્ગ સ્વિચર

એક owner account હેઠળ બહુ organizations હોય ત્યારે org switcherથી context બદલી શકાય છે.

## કેવી રીતે કામ કરે છે

1. Header/sidebar માં org switcher ખોલો
2. જરૂરી organization પસંદ કરો
3. Dashboard, transactions અને operators selected org પ્રમાણે લોડ થાય છે

<Callout title="મલ્ટી-ઓર્ગ કાર્ય" type="info">
  Org બદલીને કામ કરતી વખતે હંમેશા selected org ચકાસો, ખાસ કરીને data entry પહેલાં.
</Callout>
