# Transactions

**Route:** `/transactions`

The Transactions page is the central record of all weighing operations. Every time an operator records a weighment through the mobile wizard, it appears here.

![Transactions](/screenshots/app-transactions.png)

## Summary Cards

Three cards at the top:

| Card | Description |
| --- | --- |
| **Total Transactions** | Count of transactions in current view |
| **Total Weight** | Sum of net weight (kg) |
| **Total Amount** | Sum of total amount (₹) |

## Collapsible Filter Bar

A comprehensive filter panel that can be expanded/collapsed:

| Filter | Type | Description |
| --- | --- | --- |
| **Search** | Text | Search by receipt #, operator name, or agent name |
| **Date From** | Date | Start date for range filter |
| **Date To** | Date | End date for range filter |
| **Produce** | Combobox | Select produce type (with search) |
| **Grade** | Combobox | Select quality grade (with search) |
| **Commission Agent** | Combobox | Select agent (with search) |
| **Clear All** | Button | Reset all filters |

Active filter count is shown on the filter toggle button.

## Transaction Table

A sortable table with 13 columns:

| Column | Sortable | Description |
| --- | --- | --- |
| Checkbox | No | Select row for bulk export |
| Receipt # | Yes | Unique receipt identifier |
| Time | Yes | Transaction timestamp |
| Commission Agent | Yes | Agent name |
| Produce | Yes | Produce type |
| Grade | No | Quality grade badge |
| Net Weight | Yes | Final weight in kg (right-aligned) |
| Bachku Weight | Yes | Additional weight measure |
| Rate/20kg | Yes | Price per 20kg unit |
| Total Amount | Yes | Calculated total (bold) |
| Commission % | Yes | Agent commission rate |
| Net Amount | Yes | Amount after commission (bold) |
| View | No | Eye icon to open detail dialog |

## Transaction Detail Dialog

Clicking the view icon opens a full receipt preview:

<Tabs items={['Receipt Layout', 'Actions']}>
  <Tab value="Receipt Layout">
    - **Header:** Platform name, receipt number, date/time
    - **Agent Details:** Commission agent name and code
    - **Produce:** Type with Gujarati name, quality grade
    - **Bags:** Bag type, count, individual weights (if 10 or fewer bags)
    - **Weight Summary:** Gross weight, tare weight, net weight, bachku weight
    - **Amount:** Rate per 20kg, total units, total amount
    - **Footer:** Operator name, "Generated by TolaMandi"
  </Tab>
  <Tab value="Actions">
    - **Print** — Opens browser print dialog with receipt-optimized styling
    - **Edit** — Opens the Edit Transaction Dialog (owner/admin only)
  </Tab>
</Tabs>

## Edit Transaction Dialog

Allows editing key transaction values:

| Field | Description |
| --- | --- |
| Rate per 20kg | Update the price |
| Total Units | Modify unit count |
| Total Amount | Adjust the total |
| Notes | Add or edit notes |

## CSV Export

Two export options at the top of the table:

| Button | Description |
| --- | --- |
| **Export All** | Downloads all visible transactions as CSV |
| **Export Selected** | Downloads only checkbox-selected rows (shown when rows are selected) |

The CSV includes: Receipt #, Time, Agent, Produce, Grade, Net Weight, Rate, Amount, Commission, Net Amount.

<Callout title="Column Note" type="info">
  Gross Weight and Tare Weight columns were removed from the CSV export per T-3 requirements. Only Net Weight is exported.
</Callout>
