# ઓપરેટર્સ

**રૂટ:** `/operators`

ઓપરેટર એ ફીલ્ડ સ્ટાફ છે જે વજન ટ્રાન્ઝેક્શન દાખલ કરે છે.

![Operators](/screenshots/app-operators.png)

## સુવિધાઓ

- નવો operator ઉમેરો
- Edit operator વિગતો
- PIN reset
- Activate / Deactivate

## ટેબલ કૉલમ્સ

Name, Phone, Status, Last Login, Actions

<Callout title="સુરક્ષા" type="warn">
  PIN રીસેટ કર્યા પછી operatorને નવો PIN સુરક્ષિત રીતે શેર કરો.
</Callout>
