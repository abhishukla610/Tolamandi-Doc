# Commission Agents

**Route:** `/masters`

Commission agents are the traders and brokers who bring produce to your market yard. This page manages your agent registry and provides access to the APMC group shared agent pool.

![Commission Agents](/screenshots/app-commission-agents.png)

## Commission Agent Table

A paginated table (10 items per page) with search:

| Column | Description |
| --- | --- |
| **Code** | Auto-generated code (SA001, SA002, SA003...) |
| **Name** | Agent full name |
| **Phone** | Contact number |
| **Commission Rate** | Default commission percentage |
| **Taluka** | Market area region |
| **Status** | Active (green) or Inactive (gray) badge |
| **Actions** | Edit, Deactivate/Reactivate |

**Search** filters by name or code.

## Add / Edit Agent Dialog

<Tabs items={['Form Fields', 'Auto-Code', 'Taluka Suggestions']}>
  <Tab value="Form Fields">
    | Field | Required | Validation |
    | --- | --- | --- |
    | Code | Auto-filled | Auto-generated, always disabled |
    | Name | Yes | Cannot be empty |
    | Phone | Yes | 10 digits, unique per org (active agents only) |
    | Commission Rate | No | 0–100% |
    | Email | No | Valid email format |
    | Address | No | Free text |
    | Taluka | No | Market area (enables cross-org suggestions) |
    | GST Number | No | 15 characters |
  </Tab>
  <Tab value="Auto-Code">
    Agent codes are automatically generated by `generateNextCommissionAgentCode()`:

    <Steps>
      <Step>Query existing agents for the organization</Step>
      <Step>Find the highest numeric suffix (e.g., SA003 → 3)</Step>
      <Step>Increment and pad (3 → 4 → SA004)</Step>
      <Step>Pre-fill the Code field (always disabled)</Step>
    </Steps>

    The code field is always disabled — users cannot manually set or edit agent codes.
  </Tab>
  <Tab value="Taluka Suggestions">
    When **adding** a new agent (not editing), if you enter a taluka value:

    1. The system searches for agents in the same taluka from **other organizations**
    2. Suggestions appear below the form with agent name, phone, and org name
    3. Click **"Copy details"** to pre-fill name, phone, and other fields
    4. This uses `getCommissionAgentsByTaluka()` — a cross-org lookup

    Suggestions are **not shown when editing** an existing agent.
  </Tab>
</Tabs>

## APMC Group Agent Pool

If your account is assigned to an APMC group, an additional section appears below the agent table:

### Pool Table

| Column | Description |
| --- | --- |
| **Name** | Agent name from another organization |
| **Phone** | Contact number |
| **Taluka** | Market area |
| **Organization** | Which org this agent belongs to |
| **Status** | Agent status |
| **Action** | "Take" button |

### How "Take" Works

<Steps>
  <Step>Click **"Take"** on a pool agent</Step>
  <Step>Agent details (name, phone, taluka, GST) are copied to your organization</Step>
  <Step>A new auto-generated code is assigned (e.g., SA005)</Step>
  <Step>The agent appears in your Commission Agents table as a new entry</Step>
</Steps>

<Callout title="No APMC Group" type="info">
  If your account is not assigned to an APMC group, an info card is shown explaining the feature. Contact your platform administrator to be assigned to a group.
</Callout>

<Callout title="Phone Uniqueness" type="warn">
  Phone numbers must be unique per organization among active agents. The validation runs during both create and update operations.
</Callout>
