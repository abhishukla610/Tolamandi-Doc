# યુઝર સેટિંગ્સ

**રૂટ:** `/settings/user`

આ પેજ owner account માટે વ્યક્તિગત સેટિંગ્સ મેનેજ કરવા ઉપયોગી છે.

## મુખ્ય વિકલ્પો

- Full name અને profile info update
- Password change
- Contact details update
- Language/theme preference

<Callout title="સિક્યોરિટી" type="warn">
  મજબૂત પાસવર્ડ રાખો અને સમયાંતરે બદલતા રહો.
</Callout>
