# આર્કિટેક્ચર

Krishiv modular architecture અપનાવે છે જેમાં frontend (Next.js), backend (Supabase) અને role-based interfaces સામેલ છે.

## મુખ્ય સ્તરો

- Presentation Layer: App Router આધારિત UI
- Service Layer: business logic અને API calls
- Data Layer: PostgreSQL + RLS

## Role-based Modules

- Super Admin module
- Owner/Admin module
- Mobile operator module

  આ design multi-organization growth અને role isolation માટે optimize કરાયેલ છે.
