## Backend Stack (Supabase)

| Feature | Usage |
| --- | --- |
| **PostgreSQL** | Primary database with 15+ tables, views, enums, and indexes |
| **Row-Level Security** | All tables protected with RLS policies filtering by `organization_id` |
| **Auth (GoTrue)** | Email/password for admins, email-based auth for operators |
| **Realtime** | WebSocket subscriptions for live transaction updates and notifications |
| **RPC Functions** | SECURITY DEFINER functions for cross-org operations (e.g., `get_apmc_group_commission_agents`) |
| **Edge Functions** | Custom serverless functions for specialized operations |

<Callout title="Security Definer Functions" type="warn">
  All SECURITY DEFINER functions include `SET search_path = 'public'` to prevent schema hijack attacks. This was verified through Supabase security advisors.
</Callout>
