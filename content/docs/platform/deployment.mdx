# Deployment

Krishiv is deployed on **Vercel** with automatic CI/CD from GitHub.

## Deployment Pipeline

<Steps>
  <Step>
    ### Code Push
    Developer pushes code to `main` branch on `github.com/Abhiigg/krishiv-app`.
  </Step>
  <Step>
    ### Vercel Auto-Deploy
    Vercel detects the push and automatically triggers a build using Next.js build pipeline with Turbopack.
  </Step>
  <Step>
    ### Build & Optimize
    Next.js compiles, tree-shakes, and optimizes the application. Static pages are pre-rendered, dynamic routes are configured for edge/serverless.
  </Step>
  <Step>
    ### Deploy to Edge
    The built application is deployed to Vercel's global edge network, available at `krishiv-fresh.vercel.app`.
  </Step>
</Steps>

## Environment Variables

The application requires the following environment variables (set in Vercel dashboard):

| Variable | Description |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anonymous (public) API key |

<Callout title="Security" type="info">
  Only the `NEXT_PUBLIC_` prefixed variables are exposed to the browser. The Supabase anon key is safe to expose as RLS policies enforce all access control.
</Callout>
