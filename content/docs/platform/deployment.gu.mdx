# ડિપ્લોયમેન્ટ

TolaMandi web app Vercel પર deploy થાય છે અને code GitHub repositoryમાંથી auto-deploy થાય છે.

<Steps>
  <Step>
    main branchમાં ફેરફાર push કરો
  </Step>
  <Step>
    Vercel build શરૂ કરે છે
  </Step>
  <Step>
    Environment variables inject થાય છે
  </Step>
  <Step>
    સફળ build પછી production release થાય છે
  </Step>
</Steps>
