# Database Schema

Krishiv uses **Supabase PostgreSQL** with a normalized schema. All tables use `uuid` primary keys with auto-generation and enforce multi-tenant isolation through `organization_id` foreign keys.

## Data Mapping Convention

Database uses **snake_case**. Application uses **camelCase**. Mapper functions handle conversion:

```typescript
// Example: mapDbTransactionToApp()
{
  receipt_number  →  receiptNumber
  commission_agent_id  →  commissionAgentId
  net_weight  →  netWeight
  rate_per_20kg  →  ratePer20kg
}
```

<Callout title="UUID Handling" type="warn">
  Supabase UUID columns reject empty strings `""`. Always use `null` for optional foreign key fields, never empty string.
</Callout>
