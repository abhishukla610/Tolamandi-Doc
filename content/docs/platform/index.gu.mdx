# Krishiv પ્લેટફોર્મ

Krishiv ગુજરાતના APMC યાર્ડ માટે બનાવાયેલ multi-tenant SaaS પ્લેટફોર્મ છે, જે વજન અને ટ્રેડિંગ પ્રક્રિયાને ડિજિટલ બનાવે છે.

<Callout title="Production" type="info">
  પ્લેટફોર્મ live પર બહુ organizationsને data isolation સાથે સેવા આપે છે.
</Callout>

## શું કરે છે?

| ક્ષમતા | વર્ણન |
| --- | --- |
| Weighing Management | ઓપરેટર mobile workflowથી વજન નોંધે છે |
| Transaction Tracking | દરેક વજન માટે receipt અને amount ગણતરી |
| Multi-Organization | એક ઓનરથી બહુ organizations મેનેજ |
| Agent Registry | Commission agentsનું કેન્દ્રીય મેનેજમેન્ટ |
| Subscription Plans | tier-based plans અને limits |
| Bilingual UI | English + Gujarati support |
