# સુપર એડમિન ડેશબોર્ડ

**રૂટ:** `/superadmin/dashboard`

ડેશબોર્ડ આખા પ્લેટફોર્મનું ઉચ્ચ સ્તરીય દૃશ્ય આપે છે, જેમાં મુખ્ય મેટ્રિક્સ, સબ્સ્ક્રિપ્શન વિતરણ અને તાજેતરની પ્રવૃત્તિનો સમાવેશ થાય છે.

![Super Admin Dashboard](/screenshots/app-superadmin-dashboard.png)

## સ્ટેટ કાર્ડ્સ

ઉપરના ભાગમાં દર્શાવાતા ચાર સારાંશ કાર્ડ્સ:

| કાર્ડ | આઇકન | વર્ણન |
| --- | --- | --- |
| **કુલ સંસ્થાઓ** | Building2 | તમામ નોંધાયેલ સંસ્થાઓની સંખ્યા (સક્રિય સંખ્યასთან) |
| **એડમિન યુઝર્સ** | Users | પ્લેટફોર્મ પરના કુલ ઓનર અને બાયર એડમિન |
| **ઓપરેટર્સ** | Activity | તમામ સંસ્થાઓમાં કુલ ફિલ્ડ ઓપરેટર્સ |
| **સબ્સ્ક્રિપ્શન્સ** | CreditCard | સક્રિય સબ્સ્ક્રિપ્શનની સંખ્યા |

## સબ્સ્ક્રિપ્શન વિતરણ

બધા વપરાશકર્તાઓમાં સબ્સ્ક્રિપ્શન પ્લાનોનું વિતરણ દર્શાવતો સારાંશ કાર્ડ:
- દરેક પ્લાન નામ સાથે સબ્સ્ક્રાઇબર સંખ્યા દર્શાવે છે
- સૌથી લોકપ્રિય ટિયર ઓળખવામાં મદદ કરે છે
- પ્રાઇસિંગ માટે વ્યાપારી નિર્ણય લેવામાં ઉપયોગી

## તાજેતરની સંસ્થાઓ

**સૌથી તાજેતરમાં બનાવેલી 5** સંસ્થાઓ બતાવે છે:
- સંસ્થાનું નામ
- ઓનરનું નામ
- સ્ટેટસ બેજ (Active/Suspended)
- બનાવવાની તારીખ

## ઝડપી ક્રિયાઓ

સામાન્ય કાર્યો માટે ત્રણ શોર્ટકટ લિંક્સ:
1. **વપરાશકર્તા મેનેજ કરો** → User Management પેજ
2. **પ્લાન્સ મેનેજ કરો** → Subscription Plans પેજ
3. **ઓડિટ લોગ્સ જુઓ** → Audit Logs પેજ
