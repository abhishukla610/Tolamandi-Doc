# Super Admin Guide

<Video src="https://czjrrypzshezcosigaxe.supabase.co/storage/v1/object/public/demo/Super%20admin/super_admin1.mp4" title="Super Admin Overview" />

The **Super Admin** is the platform administrator with full access to manage all organizations, users, subscriptions, and platform configuration. There is typically one super admin account that oversees the entire Krishiv platform.

<Callout title="Access" type="info">
  Super Admin logs in at `/login` with email and password. After authentication, they are redirected to `/superadmin/dashboard`.
</Callout>

## Key Capabilities

| Capability | Description |
| --- | --- |
| **Organization Lifecycle** | Onboard new owners, create/suspend/reactivate organizations |
| **Subscription Management** | Edit plans, manage operator add-ons, enforce limits |
| **User Control** | Activate/deactivate owners, reset passwords, view activity |
| **Platform Configuration** | Edit platform name, tagline, email settings, security options |
| **Produce Catalog** | Add/edit/deactivate produce types with emoji icons |
| **APMC Groups** | Create market groups, assign owners, enable agent sharing |
| **Audit Trail** | View last 100 platform activities with search and filters |
| **Impersonation** | Enter any organization for troubleshooting |
