# સુપર એડમિન માર્ગદર્શિકા

<Video src="https://czjrrypzshezcosigaxe.supabase.co/storage/v1/object/public/demo/Super%20admin/super_admin1.mp4" title="સુપર એડમિન ઓવરવ્યૂ" />

**Super Admin** એ પ્લેટફોર્મ એડમિનિસ્ટ્રેટર છે, જેને તમામ સંસ્થાઓ, યુઝર્સ, સબ્સ્ક્રિપ્શન અને પ્લેટફોર્મ કન્ફિગરેશન મેનેજ કરવા માટે પૂર્ણ ઍક્સેસ હોય છે.

<Callout title="ઍક્સેસ" type="info">
  સુપર એડમિન `/login` પર email અને passwordથી લૉગિન કરે છે. Authentication પછી `/superadmin/dashboard` પર રીડાયરેક્ટ થાય છે.
</Callout>

## મુખ્ય ક્ષમતાઓ

| ક્ષમતા | વર્ણન |
| --- | --- |
| **સંસ્થા લાઇફસાયકલ** | નવા ઓનર ઑનબોર્ડ, સંસ્થા create/suspend/reactivate |
| **સબ્સ્ક્રિપ્શન મેનેજમેન્ટ** | પ્લાન એડિટ, ઓપરેટર એડ-ઓન મેનેજ, લિમિટ અમલ |
| **યુઝર કંટ્રોલ** | ઓનર activate/deactivate, પાસવર્ડ રીસેટ, પ્રવૃત્તિ જુઓ |
| **પ્લેટફોર્મ કન્ફિગરેશન** | પ્લેટફોર્મ નામ, ટૅગલાઇન, ઇમેઇલ અને સિક્યોરિટી સેટિંગ્સ |
| **પ્રોડ્યુસ કેટલોગ** | ઇમોજી આઇકન સાથે પ્રોડ્યુસ પ્રકાર add/edit/deactivate |
| **APMC ગ્રૂપ્સ** | માર્કેટ ગ્રૂપ બનાવો, ઓનર અસાઇન કરો, એજન્ટ શેરિંગ સક્ષમ કરો |
| **ઓડિટ ટ્રેલ** | છેલ્લી 100 પ્રવૃત્તિઓ સર્ચ/ફિલ્ટર સાથે જુઓ |
| **ઇમ્પરસોનેશન** | ટ્રબલશૂટિંગ માટે કોઈપણ સંસ્થામાં પ્રવેશ |
