# ઓપરેટર માર્ગદર્શિકા

<Video src="https://czjrrypzshezcosigaxe.supabase.co/storage/v1/object/public/demo/Operator/operator.mp4" title="ઓપરેટર ઓવરવ્યૂ" />

**ઓપરેટર** તરીકે તમે ક્ષેત્ર પર રોજ-બ-રોજની વજન અને ટ્રેડિંગ કામગીરી સંભાળો છો. સરળ ઇન્ટરફેસ દ્વારા ટ્રાન્ઝેક્શન નોંધો, પ્રોડ્યુસ એન્ટ્રી મેનેજ કરો અને રસીદ જનરેટ કરો.

<Callout title="લોગિન" type="info">
  ઓપરેટર્સ `/login` પર ઓર્ગેનાઇઝેશન ઓનર દ્વારા આપવામાં આવેલ credentials વડે લોગિન કરે છે.
</Callout>
